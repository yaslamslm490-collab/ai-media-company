# AI Media OS Dashboard

واجهة عربية تفاعلية باتجاه RTL لإدارة عمليات استوديو إعلامي مدعوم بالذكاء الاصطناعي. بدأ المستودع كهيكل فارغ؛ هذه النسخة تضيف لوحة تشغيل أمامية متجاوبة دون إطار عمل أو اعتماديات بناء.

## التشغيل

افتح `index.html` مباشرة أو شغّل خادماً محلياً من جذر المستودع:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## الموجود في هذه النسخة

- نظرة عامة مع مؤشرات أداء ورسوم مبسطة ومحتوى قيد العمل ومهام قابلة للتأشير.
- صفحات استوديو المحتوى، مكتبة الوسائط، تقويم النشر، التحليلات، سير العمل، الفريق، والإعدادات.
- إنشاء عناصر محتوى جديدة، البحث، قائمة الإشعارات، والتنقل السريع عبر `⌘/Ctrl + K`.
- حفظ تغييرات المسودات والمهام والإعدادات محلياً في المتصفح عبر `localStorage`.
- تصميم RTL متجاوب للشاشات الصغيرة والكبيرة.

## حدود التكامل

هذه واجهة أولية عاملة ببيانات توضيحية محفوظة محلياً. لا تتصل حالياً بخدمات توليد الصور/الفيديو/الصوت، أو واجهات النشر والتحليلات الحية، أو قاعدة بيانات مشتركة أو تسجيل دخول. يلزم إعداد خلفية ومفاتيح تكامل وصلاحيات للخدمات المطلوبة قبل اعتبارها إنتاجية متعددة المستخدمين.
