# AI Media OS — مركز التحكم

تطوير تدريجي للواجهة الموجودة في المستودع؛ لا يعيد بناء المشروع من الصفر. الواجهة عربية RTL ومتجاوبة، والخادم مبني على مكتبة Python القياسية، وقاعدة البيانات SQLite.

## ما وُجد في المستودع عند التدقيق

كان المستودع يحتوي على صفحة HTML وCSS وJavaScript فقط. كانت مؤشرات الوصول والتفاعل والمحتوى والفريق والوسائط والتقويم مبنية على قيم ثابتة وبيانات توضيحية مخزنة في `localStorage`. لم توجد خدمة خلفية، قاعدة بيانات، مصادقة، API، سجل نشاط، نظام شخصيات، تكامل تطبيق مع Manus أو GitHub، أو واجهة نشر/تحليلات حية. جرى تشغيل النسخة الحالية قبل التعديل، وتأكد أن `/` يستجيب بـ HTTP 200.

> استخدام GitHub لسحب هذا المستودع ودفع تغييراته لا يعني أن لوحة التطبيق مرتبطة بحساب GitHub أو أن التكامل مُهيأ داخل التطبيق.

## ما تعمل عليه هذه المرحلة

- لوحة تنفيذية تقرأ أعداد المهام والموافقات والنشاط من قاعدة SQLite، وتفصل صراحةً بين الصفر الفعلي و«غير مهيأ».
- REST API للمهام: إنشاء، بحث/تصفية، وتغيير الحالة بين `TODO` و`IN_PROGRESS` و`WAITING_APPROVAL` و`COMPLETED` و`CANCELLED` و`FAILED`.
- REST API للموافقات: إنشاء طلب، قرار `APPROVE` أو `REJECT` أو `REQUEST_CHANGES`، وتخزين القرار والملاحظة والفاعل والتوقيت؛ لا يمكن استبدال قرار الطلب بعد البت فيه.
- سجلات SQLite للأقسام وموظفي الذكاء الاصطناعي والشخصيات الرقمية والمشاريع، مع صفحات خاصة لعرضها وعدّادات مشتقة من قاعدة البيانات.
- رسم شريطي حي يوزع المهام حسب الحالة، بالإضافة إلى مهمة جارية وموافقة معلقة ضمن التهيئة الأولية.
- سجل نشاط محفوظ يتضمن الفاعل والإجراء والوحدة والعنصر والوقت والحالة والنتيجة أو الخطأ. تُسجل أخطاء العمليات الموثقة أيضاً.
- فحص صحة فعلي للخادم وSQLite وموجّه النماذج وManus وGitHub عند توفر اعتماد قابل للتحقق.
- أساس معياري لمنشئ الشركة وسجل مركزي للوحدات؛ الوحدات غير المنفذة موسومة «غير مهيأ» أو «قريباً» ولا تعرض بيانات وهمية.
- حماية افتراضية: كل API خاص يتطلب رمز المالك. عند غياب الرمز يعمل فحص الصحة والواجهة العامة فقط، وتُرفض قراءة بيانات الشركة وكتابتها.
- لا تُعرض الملفات الخاصة أو قاعدة البيانات كملفات ثابتة. قاعدة SQLite المحلية وملف `.env` مستثنيان من Git.

## تشغيل محلي

من جذر المستودع:

```bash
cp .env.example .env
python3 -c "import secrets; print(secrets.token_urlsafe(32))"
```

ضع القيمة المطبوعة في `OWNER_API_TOKEN` داخل `.env`، ثم شغّل:

```bash
python3 -m backend.server
```

لتكوين بيانات تأسيسية قابلة لإعادة التشغيل دون تكرار، شغّل مرة واحدة أو عند الحاجة:

```bash
python3 -m backend.seed
```

افتح `http://127.0.0.1:8080` وأدخل الرمز في نافذة دخول المالك. يُحفظ في `sessionStorage` للجلسة الحالية فقط. لا تشارك الرمز أو تضعه في ملفات الواجهة أو Git. يمكن تغيير `HOST` و`PORT` و`AI_MEDIA_DB_PATH` بمتغيرات بيئة.

إذا لم تضبط `OWNER_API_TOKEN`، ستُظهر لوحة التحكم الحالة «غير مهيأ» وتُغلق مسارات بيانات المالك؛ هذا مقصود وليس عطلاً. لا تُشغّل خدمة مكشوفة للإنترنت دون إعداد سر قوي وطبقة نشر آمنة مناسبة.

## فحص التكاملات

لا توجد أسرار تكامل في المستودع. يمكن ضبط قيم الخادم التالية اختياريّاً في `.env` أو بيئة التشغيل:

- `AI_ROUTER_HEALTH_URL` و`AI_ROUTER_API_KEY` لتحديد فحص مخصص. بدونهما يستخدم الخادم تلقائياً `OPENAI_API_BASE` و`OPENAI_API_KEY` إذا كانا موجودين، ويتحقق عبر `/models`.
- `MANUS_API_KEY` أو `MANUS_API_TOKEN`: يفحص الخادم `GET https://api.manus.ai/v2/task.list?limit=1` باستخدام ترويسة `x-manus-api-key`. يمكن تغيير المسار بواسطة `MANUS_HEALTH_URL`. يظل Manus غير مهيأ حتى توفير مفتاح API دائم عبر موصل Manus API الآمن.
- `GITHUB_USE_CLI=true`: يستخدم الخادم اعتماد `gh` الموجود على المضيف عبر `gh api user` ولا ينسخ الرمز أو اسم الحساب إلى استجابة الصحة. أو يمكن ضبط `GITHUB_TOKEN` و`GITHUB_HEALTH_URL`؛ عند إغفال الرابط يستخدم `https://api.github.com/user`.
- `EXTERNAL_HEALTH_URLS`: كائن JSON يربط أسماء التكاملات بنقاط فحص GET عامة. لا تُدرج أسراراً في هذه القيمة.

لا تُعرض قيم الرموز للمتصفح. وغياب الإعداد ينتج `NOT_CONFIGURED`، وفشل الاتصال ينتج `OFFLINE` أو `ERROR`؛ لا تُعلَن حالة `ONLINE` إلا بعد استجابة ناجحة.

## API

| الطريقة | المسار | الصلاحية | الوظيفة |
|---|---|---|---|
| `GET` | `/api/health` | عام | فحص حالة الخادم وقاعدة البيانات والمصادقة والتكاملات |
| `GET` | `/api/modules` | عام | تسجيل الوحدات وحالاتها وقدرات Company Builder المستقبلية |
| `GET` | `/api/dashboard` | رمز المالك | المؤشرات الحقيقية والمهام/الموافقات/النشاط الأخير |
| `GET` | `/api/company` | رمز المالك | الأقسام والموظفون والشخصيات والمشاريع |
| `GET`, `POST` | `/api/tasks` | رمز المالك | قراءة المهام وإنشاؤها |
| `PATCH` | `/api/tasks/{id}` | رمز المالك | تحديث حالة مهمة |
| `GET`, `POST` | `/api/approvals` | رمز المالك | قراءة الطلبات وإنشاء طلب مراجعة |
| `PATCH` | `/api/approvals/{id}` | رمز المالك | تسجيل قرار نهائي وملاحظة |
| `GET` | `/api/approvals/{id}/decisions` | رمز المالك | قراءة تاريخ القرارات المحفوظ |
| `GET` | `/api/activity` | رمز المالك | قراءة سجل التدقيق مع البحث والتصفية |

أرسل الرمز في الترويسة `X-Owner-Token`. لا تُفعّل CORS عبر مصادر أخرى.

## قاعدة البيانات والتوسع

ينشئ الخادم `data/dashboard.sqlite3` والجداول عند التشغيل الأول. ينشئ `python3 -m backend.seed` سجلات مبدئية ثابتة المعرّفات للقسم والموظف والشخصية والمشروع والمهمة والموافقة؛ إعادة تشغيله لا تنشئ نسخاً مكررة ولا تستبدل سجلات المالك. تشمل الجداول `departments` و`ai_employees` و`characters` و`projects` إلى جانب `tasks` و`approvals` و`approval_decisions` و`activity_logs`. قاعدة البيانات مستثناة من Git. لتعدد المستخدمين والصلاحيات والبيئة الإنتاجية الدائمة، ينبغي نقل التخزين إلى قاعدة مُدارة وإضافة هوية مستخدمين/جلسات قبل تعريض النظام لعدة مشغلين.

## الاختبارات

```bash
python3 -m compileall -q backend tests
python3 -m unittest discover -s tests -v
```

نجحت 13 حالة اختبار تغطي الصحة الفعلية ومسارات OpenAI-compatible وManus وGitHub CLI، تكرارية seed والعرض عبر API والعدادات، غياب المصادقة والرمز الخطأ، إنشاء المهام وتغيير حالتها، قرارات الموافقة وحفظ سجل القرار، فلاتر النشاط، والتحقق من عدم تقديم ملفات Backend أو قاعدة البيانات كملفات ثابتة.

## ما لم يُنفذ بعد

لا يوجد حساب دخول متعدد المستخدمين أو RBAC، ولا خدمة نشر دائم/قاعدة مشتركة، ولا عمليات محتوى أو إدارة مستودعات عبر AI Router أو Manus أو GitHub من داخل اللوحة؛ المتاح حالياً فحص صحة الاتصال فقط. في بيئة المعاينة الحالية نجح فحص OpenAI-compatible وGitHub CLI. يقرأ Manus API مفتاحاً دائماً من `MANUS_API_KEY` بعد أن يضيفه المالك عبر بطاقة الإعداد الآمنة؛ لا يُدّعى `ONLINE` قبل نجاح الفحص الفعلي. كما لا توجد بيانات إنتاجية سابقة للشخصيات أو المحتوى أو الإنتاج أو الوسائط أو التحليلات.
