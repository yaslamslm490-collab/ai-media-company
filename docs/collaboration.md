# التعاون المدمج في NADA AI

## التصميم

قاعدة NADA AI هي السجل الأساسي للمهام والحالة والنتائج. لا تُنشأ قاعدة بيانات أو خدمة Bridge جديدة: يضيف ترحيل قاعدة البيانات `004-collaboration-v1` جدول روابط Manus وجدول تحديثات المهمة، ويربطهما بجدول `tasks` الموجود. واجهات لوحة المهام تعرض سجل التحديثات. خادم Python نفسه يخدم MCP على `POST /mcp` وManus callback على `/api/collaboration/manus/webhook`.

أدوات MCP تشمل قراءة المهام وإنشاءها وتحديثها وحفظ النتائج وإرسالها إلى Manus ومزامنتها وإرسال رد متابعة وتسجيل Webhook. أداة `create_and_send_task_to_manus` تنشئ سجلًا واحدًا في NADA AI ثم ترسل نص المهمة إلى Manus API الرسمي مع خصوصية `private`. قد يؤدي إرسال المهمة إلى تشغيل عمل Manus واستهلاك حصص الحساب؛ لم يُرسل أي طلب حي خلال التطوير.

## إعداد الخادم

أضف المتغيرات إلى مدير أسرار مضيف التطبيق (أو `.env` محليًا فقط، وهو مستثنى من Git):

- `MANUS_API_KEY`: مفتاح Manus API. يبقى في الخادم ولا يُرسل إلى ChatGPT.
- `NADA_MCP_TOKEN`: رمز Bearer عشوائي مخصص لاتصال MCP؛ أنشئ قيمة قوية محليًا، ولا تعِد استخدام كلمة مرور المالك.
- `PUBLIC_BASE_URL`: أصل HTTPS دائم مثل `https://nada.example.com` بلا مسار أو شرطة أخيرة؛ مطلوب لتسجيل Manus Webhook.

بعد الإعداد، نقطة الصحة `GET /api/collaboration/status` تميّز بين `CONFIGURED` و`NOT_CONFIGURED`؛ لا تعني الحالة المهيأة وحدها أن اختبارًا حيًا نجح. يمكن للمالك استخدام أداة `register_manus_webhook` مرة واحدة؛ تتحقق من القائمة أولًا ولا تنشئ تسجيلًا ثانيًا لنفس الرابط. Manus يوقّع كل إشعار ويُتحقق من توقيعه RSA-SHA256 وعمره خلال خمس دقائق. إشعار التوقف يشغّل مزامنة لاحقة، ولا تُصبح المهمة `COMPLETED` إلا بعد أن يؤكد `task.detail` أن الحالة `stopped` وأن `has_running_background_jobs` تساوي `false`؛ الغياب أو الخطأ يبقي الاكتمال غير مؤكد.

## اتصال OpenAI / ChatGPT

الخادم يطبق النقل Streamable HTTP على `/mcp` ويحميه برمز Bearer مستقل. يمكن اختبار البروتوكول أو استدعاؤه من عميل MCP/API يدعم تمرير Bearer token. لم يُنفّذ OAuth 2.1 الخاص بموصلات MCP المخصصة في ChatGPT؛ لذلك **لا تعتبر اتصال ChatGPT Web ناجحًا أو جاهزًا للإضافة قبل إنشاء تدفق OAuth 2.1 وفحصه**. لا توضع `MANUS_API_KEY` في OpenAI أو ChatGPT.

وفق مركز مساعدة OpenAI الحالي (تاريخ الفحص 2026-10-11)، MCP مخصص مع الكتابة متاح ضمن طرح Business وEnterprise/Edu؛ Pro يتيح القراءة/الجلب فقط بوضع المطور، ولا يُفترض توفر ذلك على Free. لذلك لا يستطيع حساب Free الحالي تنفيذ أدوات الكتابة المخصصة داخل ChatGPT Web. تحديث مخطط الأدوات في تطبيق ChatGPT يتطلب كذلك تحديث/مراجعة connector لدى مسؤول مساحة العمل.

## اختبار محلي بلا أسرار أو اتصال خارجي

```bash
python3 -m unittest tests.test_collaboration -v
pnpm test
```

الاختبارات تستخدم قاعدة مؤقتة واعتمادًا وهميًا داخل الاختبار فقط، وتحاكي Manus API. لا تُنشئ مهمة حية ولا تسجل Webhook لدى Manus. قبل الإنتاج، يلزم نشر هذا المستودع نفسه على HTTPS دائم، ثم إدخال الأسرار أعلاه في مدير أسرار المضيف واختبار الاتصال الحي بإذن المالك.

## Bridge القديم

يبقى مجلد `bridge/` مؤقتًا للتوافق والمرجعية، لكنه ليس مسار التشغيل المعتمد ولا ينبغي نشره بالتوازي. يستخدم قاعدة منفصلة؛ لم تُحذف ملفاته أو قواعد بياناته ولم تُنقل بياناته. بعد التأكد من عدم وجود خدمة قديمة أو بيانات مطلوبة، يمكن اتخاذ قرار مستقل بإزالته.
